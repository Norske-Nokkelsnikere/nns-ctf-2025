# Viewing Pulses
The attached file contains a PulseView recording of some UART transmissions.

The file can be opened in PulseView, where a UART decoder can be used. 
Channel 1 is TX, the others are RTS, CTS and RX, but do not matter.
The baud rate is 115200.

One can verify that letters are seen if using ASCII representation.

The data can then be exported to file by right-clicking the line of decoded data and clicking export.
After removing non-important parts of the file one will find the flag, `NNS{an4lys1ng_pu1s35_t0_dec0d3_f1ag5}`, encapsulated in the lyrics of *Tore Tang* by Mods.
